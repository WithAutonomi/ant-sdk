# @withautonomi/ant-ffi

Direct-network (daemon-less) [Autonomi](https://autonomi.com) client for
**Node.js and Electron** — a native addon over the same Rust core the Swift,
Kotlin, C# and Python bindings use. No running `antd` daemon, no Rust toolchain
at install time: `npm install` pulls a prebuilt binary for your platform.

> Need a daemon-backed client (REST/gRPC to a running `antd`) instead? Use the
> [`antd`](../../antd-js) package. This one embeds the network client in your
> process.

## Install

```bash
npm install @withautonomi/ant-ffi
```

The main package declares per-platform binaries as `optionalDependencies` with
`os`/`cpu` constraints, so npm installs only the one prebuilt `.node` matching
your platform — no `node-gyp`, no postinstall compile. On an unsupported
platform, `require` throws a clear error at load time.

## Quick start

```js
import { Client, PaymentMode } from '@withautonomi/ant-ffi'

// One Client per process (see below). Production, read + write:
const client = await Client.connectDefaultWithWallet(process.env.EVM_PRIVATE_KEY)

// Upload bytes publicly, then read them back by address.
const put = await client.dataPutPublic(Buffer.from('hello autonomi'), PaymentMode.Auto)
console.log('stored at', put.address, '—', put.chunksStored, 'chunks')

const bytes = await client.dataGetPublic(put.address) // -> Buffer
console.log(bytes.toString()) // "hello autonomi"
```

Read-only (no wallet) is `Client.connectDefault()`. For local development against
a devnet, use `Client.connectFromDevnetManifest(manifestPath)`.

### Progress callbacks

Every long-running upload/download has a `…WithProgress` variant taking a plain
JS callback. Callbacks arrive on a background thread and are marshaled to the JS
event loop for you:

```js
const res = await client.fileUploadPublicWithProgress(
  '/path/to/file',
  PaymentMode.Auto,
  (p) => console.log(p.phase, `${p.done}/${p.total}`), // Encrypting → Quoting → Storing
)
console.log('cost:', res.storageCostAtto, 'atto +', res.gasCostWei, 'wei gas')
```

### External signer (WalletConnect / hardware wallets)

For the pay-off-device flow, connect with `Client.connectDefaultForExternalSigner()`,
then `prepareFileUpload` → `paymentTransactions` (sign & send each with your
wallet) → `finalizeUpload` (wave-batch) or `finalizeUploadMerkle` (merkle). The
`waitForReceipt` and `merkleWinnerPoolHash` free functions cover the on-chain
plumbing. See the [external-signer guide](../../docs) for the full sequence.

## One `Client` per process

A `Client` **is a network peer**: `connect*` joins the network (a one-time
bootstrap latency) and the returned object holds live QUIC connections for its
lifetime. So:

- Create **one** `Client` at startup and reuse it — don't construct one per
  request.
- In Electron, create it in the **main process**; call it over IPC from
  renderers (native addons don't load in the sandboxed renderer).
- It's safe to share across concurrent async calls; methods are `async` and
  return `Promise`s driven on the addon's own runtime, so the event loop never
  blocks.

## Amounts and buffers

- Token/gas **amounts are decimal strings** (`storageCostAtto`, `gasCostWei`,
  `amount`) — they exceed `Number.MAX_SAFE_INTEGER`. Counts and sizes are plain
  numbers.
- Binary data is `Uint8Array`/`Buffer` in, `Buffer` out — zero-copy into Rust.

## Platform support

Prebuilt for:

| OS | x64 | arm64 |
|---|---|---|
| Windows (msvc) | ✅ | ✅ |
| macOS | ✅ | ✅ |
| Linux (glibc) | ✅ | ✅ |
| Linux (musl / Alpine) | ✅ | ✅ |

Node 16+ (Node-API v8; one binary covers Node 16/18/20/22+ and Electron).
Browser and edge/serverless isolates (Cloudflare Workers, etc.) are **not**
supported — they can't load native addons or open UDP; use `antd` there. Bun
loads Node-API modules and mostly works, but is untested.

## Build from source (contributors)

Requires the Rust toolchain and Node 16+.

```bash
cd ffi/node
npm install
npm run build:debug   # or: npm run build   (release, optimized)
npm test              # offline smoke tests
```

`npm run build` produces the platform `.node`, `index.js` (loader) and
`index.d.ts` (types) — all git-ignored and regenerated. A live round-trip demo
against a local devnet is in [`examples/upload_download_demo.mjs`](examples/upload_download_demo.mjs).

## How it fits

This crate (`ffi/node`) is a thin [napi-rs](https://napi.rs) layer over the
`ant-ffi` Rust crate (`ffi/rust`). Unlike the other bindings — generated by
UniFFI, which has no maintained Node backend — the Node surface is mirrored by
hand with `#[napi]` wrappers that delegate to the same inner client. No business
logic lives in this crate.
